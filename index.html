首次使用？ 点击查看如何获取 Token
🔑 如何获取 GitHub Token
1. 打开 github.com/settings/tokens
2. 点击 Generate new token (classic)
3. Note 填写 "ToDo Sync"
4. Expiration 选择 No expiration（或自定义时长）
5. 勾选 gist 权限（仅此一项即可）
6. 点击页面底部 Generate token
7. 立即复制生成的 Token（只显示一次！）

将 Token 粘贴到云同步设置中，点击"推送"即可上传数据。 换设备时，输入同一个 Token 点击"拉取"即可恢复。
